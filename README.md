# 电商网站项目

基于团队协作分析结果创建的电商网站项目。

## 项目结构
```
ecommerce-project/
├── frontend/          # 前端项目
├── backend/           # 后端项目
├── docs/              # 项目文档
└── scripts/           # 部署脚本
```

## 技术栈
### 前端
- React 18 + TypeScript
- Vite 构建工具
- Ant Design + Tailwind CSS
- Zustand + React Query

### 后端
- Go (Golang) + Gin
- PostgreSQL 数据库
- Redis 缓存
- RabbitMQ 消息队列
- 微服务架构

## 核心功能
1. 用户系统（注册、登录、个人信息）
2. 商品系统（分类、展示、搜索）
3. 购物车功能
4. 订单系统
5. 支付集成
6. 后台管理系统

## 开发计划
- 第一阶段（2-3周）：MVP开发
- 第二阶段（3-4周）：功能完善
- 第三阶段（1-2周）：测试上线
