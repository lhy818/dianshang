# 电商网站项目启动指南

## 环境要求

### 开发环境
- Node.js 18+ (前端)
- Go 1.21+ (后端)
- Docker & Docker Compose
- PostgreSQL 15+
- Redis 7+
- RabbitMQ 3.12+

### 推荐工具
- VS Code 或 GoLand
- Postman 或 Insomnia (API测试)
- DBeaver 或 pgAdmin (数据库管理)
- RedisInsight (Redis管理)

## 快速开始

### 1. 克隆项目
```bash
git clone <项目地址>
cd ecommerce-project
```

### 2. 启动基础设施
```bash
# 使用Docker启动数据库、缓存、消息队列
docker-compose up -d postgres redis rabbitmq
```

### 3. 启动后端服务
```bash
cd backend
go mod download
go run cmd/main.go
```

### 4. 启动前端服务
```bash
cd frontend
npm install
npm run dev
```

### 5. 访问应用
- 前端: http://localhost:3000
- 后端API: http://localhost:8080
- RabbitMQ管理界面: http://localhost:15672 (admin/admin)

## API文档

### 访问Swagger UI
启动后端服务后访问: http://localhost:8080/swagger/index.html

### API端点
- `GET /api/v1/health` - 健康检查
- `POST /api/v1/auth/register` - 用户注册
- `POST /api/v1/auth/login` - 用户登录
- `GET /api/v1/products` - 获取商品列表
- `GET /api/v1/products/:id` - 获取商品详情
- `POST /api/v1/cart/items` - 添加购物车商品
- `POST /api/v1/orders` - 创建订单

## 故障排除

### 常见问题

1. **数据库连接失败**
   ```bash
   # 检查PostgreSQL是否运行
   docker ps | grep postgres
   
   # 检查连接配置
   cat backend/config/config.yaml | grep database
   ```

2. **Redis连接失败**
   ```bash
   # 检查Redis是否运行
   docker ps | grep redis
   
   # 测试Redis连接
   docker exec ecommerce-redis redis-cli ping
   ```

3. **前端构建失败**
   ```bash
   # 清理node_modules重新安装
   rm -rf frontend/node_modules
   cd frontend && npm install
   ```

4. **端口冲突**
   ```bash
   # 查看端口占用
   lsof -i :3000
   lsof -i :8080
   
   # 修改配置文件中的端口号
   ```
